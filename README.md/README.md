# ❤️ Heart Disease AI Prediction System

An AI-powered web application tool for Doctors that predicts the likelihood of heart disease using Machine Learning. It provides risk assessment, AI-generated recommendations, downloadable PDF reports, and a modern responsive interface.

## 🚀 Live Demo

**Frontend:**  
https://heart-disease-api-neon.vercel.app

**Backend API:**  
https://heart-disease-api-8r93.onrender.com

**API Documentation:**  
https://heart-disease-api-8r93.onrender.com/docs

---

## ✨ Features

- ❤️ Heart disease prediction using Machine Learning
- ⚡ FastAPI REST API
- 📱 Modern responsive user interface
- 📊 Risk probability gauge
- 🤖 AI risk analysis
- 📄 Downloadable PDF medical report
- 📜 Prediction history
- ✔ Input validation
- ☁️ Deployed with Render and Vercel

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Peakeyy-ai/heart-disease-api.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
uvicorn main:app --reload
```

Open:

```
http://127.0.0.1:8000/docs
```
